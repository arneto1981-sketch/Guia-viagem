# Guia de Bolso

PWA de guia turístico por GPS com narração em português (voz do próprio celular) e diário de viagem automático.

- Abra no Chrome Android: `https://arneto1981-sketch.github.io/Guia-viagem/`
- Menu ⋮ → **Instalar app** → permita localização → fone → **Iniciar guia**
- Funciona offline (service worker). O diário fica só no aparelho (localStorage); use *Backup do diário* para exportar.

Arquivos: `index.html` (app), `pois.json` (base de pontos), `sw.js` (offline), `manifest.json`, ícones.
